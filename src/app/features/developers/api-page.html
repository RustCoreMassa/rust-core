Rules

  • The chain is the source of truth. The API is a cache of the chain’s final state, refreshed every minute: up to about two minutes behind. Anything that moves funds — a purchase, a contribution — must be checked on chain before it is signed. The Launchpad app does exactly that.
  • Rate limit: 10 requests per second per IP address, with bursts of up to 40. Above it the answer is 429 Too Many Requests: wait a second and try again. Cache what you can — the data changes once a minute at most.
  • Hidden projects — the scams the Launchpad admin hid — are served nowhere: a 404 by address, and left out of every list and figure.
  • Strings are returned as stored on chain. Imported contracts may hold bidi or invisible characters: strip them before display, and never render them as HTML.
  • When /status says "stale": true, the indexer hasn’t read the registry for three rounds: read the chain instead.

Conventions

Amounts
nanoMAS (1 MAS = 10⁹ nanoMAS), sent as strings: "5000000000" = 5 MAS.
Big numbers
Token ids (u256) and token units (tokensForSale, rate) are strings too: they can exceed what a JavaScript number holds exactly (2⁵³). Small ids (id, listingId, collectionId) are numbers.
Times
ISO-8601 in UTC: "2026-10-19T09:59:29Z".
Addresses
As on chain: AU… for accounts, AS… for contracts. Anything else is a 400.
Enums
Query values in any case: price_asc, PRICE_ASC and price-asc are the same. Answers use lower case.

Pagination

Lists answer one page and a cursor:

{{ pageExample }}

Pass nextCursor back as cursor, with the same filters and sort, for the next page; it is null on the last one. limit is 1–200, 50 by default. Cursors are opaque (keyset pagination): a page costs the same at any depth, and items don’t shift or repeat when new ones arrive. Don’t build or edit them — a malformed cursor is a 400.

Errors

RFC 9457 problem details, as application/problem+json. detail names every bad parameter. 

{{ errorExample }}

400 for a bad parameter or cursor, 404 for an unknown address, id or path, 405 for anything but GET / HEAD, 429 above the rate limit.
